// Best Project · AI / ML · Full Stack

AgroKnight

Smart Agriculture AI Platform

An AI-powered platform built in 24 hours that helps Indian farmers detect crop diseases, get irrigation advice, and predict yields — bridging the gap between traditional farming and modern technology.

PythonOpenCVTensorFlowFastAPIReact
🚀 Live Demo ⌥ GitHub Repo
24h Built In
94% Disease Detection Accuracy
#1 Hackathon Rank
⚠️ Problem Solved
🌾 Farmers lack fast, accessible tools to diagnose crop diseases before they spread across fields.
💧 Manual irrigation decisions waste water and reduce yield — there's no AI guidance tailored to local weather.
📉 Unpredictable yields make financial planning nearly impossible for small-scale farmers in India.
⚙️ Tech Stack
🐍PythonCore ML Logic
👁️OpenCVImage Processing
🧠TensorFlowDisease Detection CNN
⚡FastAPIBackend API
⚛️ReactFrontend UI
☁️OpenWeather APIWeather Data
🔥 Challenges Faced
01
Real-Time Image Inference Under 24h

Training a CNN from scratch was infeasible in the hackathon window. Solved by using transfer learning on a pre-trained MobileNetV2 model fine-tuned on a crop disease dataset, cutting training time to under 2 hours while maintaining 94% accuracy.

02
Bridging AI Output to Actionable Farmer Advice

Raw model outputs (class labels) needed to become practical, language-accessible advice. Built a rule-based recommendation engine that maps disease categories to treatment protocols and links weather data to irrigation schedules in plain language.

03
Full-Stack Integration Sprint

Wiring FastAPI endpoints, React frontend, and the ML inference pipeline into a cohesive demo required tight coordination across the stack within hours. Solved with a strict API contract defined upfront, enabling parallel development.

✨ Key Features
📷
Crop Disease Detection

Farmers upload a photo of a leaf; OpenCV preprocesses the image and a TensorFlow CNN classifies the disease with 94% accuracy across 38 crop-disease categories.

🌦️
Weather-Based Irrigation Advice

Integrates OpenWeather API to fetch real-time and forecast data, then generates crop-specific watering schedules that adapt to rainfall predictions and temperature trends.

📊
Yield Prediction Model

A scikit-learn regression model trained on historical crop data predicts seasonal yield based on soil type, weather patterns, and crop variety to assist pre-harvest planning.

🌐
Multilingual React Dashboard

Responsive React interface with English and Telugu language support, keeping the platform accessible to rural farmers less comfortable with English-only tools.

🚀 Impact & Takeaways
🎓
End-to-End Ownership

Sole developer of the full ML pipeline, REST API, and frontend — demonstrating complete full-stack and AI/ML integration ability under pressure.

🌍
Real-World Problem Solving

Addresses a genuine gap in India's agriculture sector, where millions of small farmers lack access to data-driven advisory tools.

⏱️
Rapid Prototyping Under Constraints

Delivered a functional, demo-ready product in 24 hours — validating the ability to prioritize, scope, and ship fast without compromising core quality.
